# Isolated lightweight adapter source

This is a public-safe source adapter, not a complete dashboard, a new panel, or a production deployment. The original private adapter underwent a partial browser check; that evidence does not validate this changed public export. No browser, business, production or natural-trigger acceptance is claimed here. Charts, training, collection, freezing and delivery are not enabled. The original full-startup resource threshold is not modified.

There are deliberately no default source bindings, research dates, source versions, data, original dependency implementations, articles or lifecycle receipts. `prepare(None)` fails closed. An approved isolated original dependency closure must supply a valid historical business date, explicit selection/catalog identity, and SHA256/size pins for every file. Missing or changed dependencies, symlinks, previously loaded core modules and invalid identities reject before imports. This closure must separately be source-reviewed; matching hashes do not grant business eligibility. Runtime dependencies must use the already-approved installed environment, not download anything.

The adapter reuses the original timeline DOM and modules, original bounded server and pinned catalog/node services. The original service resource callbacks, locks, source and identity checks remain in those required dependencies. Initial memory headroom is at least 1 GiB (cgroup-aware) and disk 256 MiB; the separate full-dashboard gate remains unchanged. Loopback-only serving, Host/Origin validation, limited GET allowlist, original read-only methods and ten-minute shutdown remain. `run` needs an explicit separate local lifecycle directory and holds `preview.lock` exclusively until exit. Never put private outputs in the public source directory.

Run `PYTHONDONTWRITEBYTECODE=1 python -m unittest -v test_adapter` and repeat with `PYTHONOPTIMIZE=1`. Eight synthetic tests cover default/partial bindings, exact fixture pin integrity, tampering, unpinned files/symlinks, Host/Origin, low-memory refusal and import identity refusal. Fixtures are fabricated text, not executable private services. No HTTP server or browser is started by these tests. Full transitive runtime behavior requires independent review and acceptance with approved private bindings; this package alone cannot prove it.
