### new

```python
def _config(value):
    exact_keys(
        value,
        (
            'schema_version',
            'module_id',
            'release_id',
            'data_root',
            'm18_v2_binding',
            'routes',
        ),
    )
```

紧接加入：

```python
    if value['module_id'] == 'manager' and any(
        route == '/api/v4/manager/m18/v2/pages'
        for route in value['routes']
    ):
        binding = value['m18_v2_binding']

        exact_keys(
            binding,
            (
                'manifest_sha256',
                'identity',
                'profile_sha256',
                'bundle_root',
            ),
        )

        exact_keys(
            binding['identity'],
            (
                'run_id',
                'target_date',
                'plan_sha256',
                'raw_sha256',
                'response_sha256',
                'input_identity',
            ),
        )

        sha(binding['manifest_sha256'])
        sha(binding['profile_sha256'])

        if binding['identity']['run_id'] != \
                '46596b03c2ab4e29b1219fd2e5eb698f':
            raise ValueError('M18_BINDING_RUN_ID')
```

作用：

- 不接受任意 dict；
- 保留身份合同；
- 不放宽 exact_keys；
