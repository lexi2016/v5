# M09 historical replay: exact read-only P0 integration

## Scope and entry

GET `/api/v5/source-bundle/a-close-replay` serves only the explicitly configured historical date, model run and generation. The main source-status page has a separate “A 股历史研究回放” component after the unchanged M06/M10 components. Original four source cards and M13/M14/M15/M18 integration are not replaced.

The route never calls a producer, prepares a snapshot, reads new market data, changes a head, repairs a record, schedules a job or sends a trade. It does not select `latest` or fall back to another date/run. Unconfigured bindings return `NOT_CONFIGURED`; a configured but invalid or missing reference returns HTTP 409 with no previous review. Query selectors and all write methods are rejected.

M09, M10 and M06 have separate API read slots and separate frontend sessions. Refresh, missing configuration, disconnection, rejected identity and out-of-order replies clear or retain no old M09 rows. Other module reads stay independent.
